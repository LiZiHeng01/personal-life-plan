# 个人生活计划

一个面向青岛的纯静态个人生活计划页面：实时天气、作息、健身、社交与日常护理。没有后端、没有构建步骤，也不包含打卡。

## 功能

- **总览**：日期、北京时间、青岛实时天气、当前进行中的安排，以及当天剩余的重点事项。
- **青岛天气**：显示青岛的天气、气温、风力和湿度，附带天气图标、更新时间和防风/降水/高温提示；每 15 分钟刷新一次，成功结果在本地缓存 6 小时，接口失败会自动重试并保留上次数据。
- **每日作息**：周一至周日的完整时间表，自动区分健身日、休息日和周末。
- **季节建议**：按青岛气候切换春（4–5 月）、夏（6–9 月）、秋（10–11 月）、冬（12–3 月）提示，也可以手动预览其他季节；作息中的遛狗和护肤文案会随季节微调。
- **社交拓展**：三阶段社交路线与适合慢热性格的活动建议。
- **习惯与护理**：早晚护理、睡眠目标、固定生活原则；「每餐 · 怎么搭」给出 1 拳蛋白 / 2 拳蔬菜 / 1 拳主食的比例，「一周 · 照着吃」把周一到周日三餐写成可直接照着点的表，「每周 · 买一次」给出水果与蔬菜采购清单，另有「想瘦脸」的实话与做法。
- **内容取舍**：饮食部分只写可执行的数量与搭配（蔬菜 300–500g/天、水果 200–350g/天），不承诺局部减脂；瘦脸部分明确说明脸不能单独减、能单独处理的只有水肿。页面不提供医疗建议。
- **主题与路由**：支持深色模式并记住选择；页面使用 `#overview`、`#schedule`、`#social`、`#habits` 这样的哈希路由，刷新或分享链接不会丢失当前页面。
- **本地照片**：科比 7 张、爱德华兹 6 张、三井寿 9 张（彩色动画截图/插画），全部存放在 `assets/img/`，每天轮换；不请求任何外部图片。图片已压缩到适合卡片显示的尺寸。

## 本地使用

建议用静态服务器打开，天气接口需要 `http://` 或 `https://` 来源：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。直接双击 `index.html` 也能查看页面，但如果浏览器拦截跨域请求，天气会显示“天气暂不可用”。

## 修改内容

- **改作息**：编辑 `assets/js/data.js` 中的 `schedules`。每项是 `["时间", "安排"]`，跨午夜的时间段写成 `23:30–07:00` 即可。
- **改季节建议**：编辑 `seasonData` 里的 `walk`、`gym`、`social` 和 `skin`。自动季节的月份边界在 `assets/js/app.js` 的 `autoSeason` 中。
- **改城市/天气**：编辑 `weather` 中的 `city`、`adcode`、`url` 和来源链接。当前使用青岛 `370200`；换城市时需要换成对应城市的 adcode。
- **换照片**：把图片放进 `assets/img/`，再更新 `photoCollections` 中的 `src`、`source`、`credit` 和 `license`。建议保持 4:5 或接近的竖版比例，长边压到 480px 左右即可（卡片实际显示宽度约 200px）。
- **改主题色**：编辑 `assets/css/styles.css` 顶部的 CSS 变量。

## 本地存储

页面只在自己的浏览器里保存偏好和天气缓存：

- `lifeplan-theme`：`light` 或 `dark`
- `lifeplan-season`：`auto` 或 `spring` / `summer` / `autumn` / `winter`
- `lifeplan-weather-v1`：最近一次成功的青岛天气，保留 6 小时

除天气接口外，没有账号、cookie 或统计脚本；作息与偏好不会上传到服务器。
